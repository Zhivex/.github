# Security policy

Do not open a public issue for a suspected vulnerability.

Use the target repository's **Security → Report a vulnerability** flow. If
private vulnerability reporting is unavailable, contact
`administracion@zhivex.com` with:

- affected repository, package, and version
- impact and affected configurations
- minimal reproduction or proof of concept
- suggested mitigation, when available

Do not include live credentials, customer data, or production prompt
transcripts. Zhivex will acknowledge the report, investigate it, coordinate a
fix, and disclose it after users have had a reasonable opportunity to update.
