# Support

Use the following channel for the type of help you need:

- questions, ideas, and usage guidance:
  [TypeScript discussions](https://github.com/Zhivex/zhivex-ai-sdk/discussions)
- reproducible TypeScript defects:
  [TypeScript issues](https://github.com/Zhivex/zhivex-ai-sdk/issues)
- reproducible Python defects:
  [Python issues](https://github.com/Zhivex/zhivex-ai-sdk-py/issues)
- suspected vulnerabilities: the repository's private vulnerability reporting
  flow described in [`SECURITY.md`](./SECURITY.md)

Include package versions, runtime versions, a minimal reproduction, expected
behavior, actual behavior, and redacted logs where relevant.
